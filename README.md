# 经略三国 15.0 · 山河百年

三国回合制单人页游。184、190、199、208、219、234、262、265 年八个剧本共用 42 座主城。玩家选择一个势力，其余持有主城的势力由各自的 AI 执政。

## 运行

使用 Node.js 22 或更新版本。在项目目录运行以下命令，然后访问 [本地游戏](http://127.0.0.1:5173/)。

```powershell
npm start
```

## Vercel 部署

用 Vercel CLI 在项目目录执行 `vercel deploy --prod`。页面和素材从 `dist` 发布，模型设置、连接测试和回合结算由 `api/game.js` 提供。游戏开局可直接使用规则 AI。

公网版的模型设置保存在当前浏览器会话中。模型服务需使用公开域名和标准 HTTPS 端口。存档仍保存在当前站点的浏览器存储中，从本地版迁移时可导出备份，再到线上版导入。

在「势力」面板选择「新开局」。地图、势力和城池操作都放在同一屏，窄屏可用底部按钮切换面板。城池的「人物」页可查找文武人员及其驻地，将待任人员调来此城。「任命」页可设置太守和守将。驻在出征城的待任人员和守将可领兵出征。

在地图点城即可展开城池指令。己方城支持建设、征兵、任命、调驻、委任、出征和调兵，敌城可选择己方出发城或派斥候。出征和调兵会高亮可选城池，选中后在地图下方核对路线、耗粮、留守和预计结果，再将政令入队。返回可重新选城，并保留仍可用的编组设置。「搜索」可按城名、历史名、州郡或势力定位，桌面也可按 `/`。「议事」直达来使、州郡和战区待办，「政令」可重排、撤销或推进一季。

## 山河百年

地图上的「全国国策」打开年度方略。先选主目标和保底目标，再核对钱粮底线、军事额度和运输优先级。提交前可比较现行政策与新案的四季结算。勾选代办后，有合适人员的州郡可自动委任，续任和新城接管亦按授权执行。

从「待决」批准赈济、让权或安排交班。从地图点本方城池，再选「州郡委任」，可续任州牧或协商留粮与财政义务。战区优先级会改变全国拨款顺序。城池接管、居民迁入及军队和粮队占用的劳力会进入后续产粮。

拓土立制、保境成约和再整山河各有结卷条件，见「纪事」。达到结局后可保留本章纪录，继续在原局安排继任和守成。纪事可对照最近 193 个季度的城池归属、钱粮、人口和运粮状态，另保留最近 58 场本方战斗。

旧档从「菜单 → 山河百年」升级，迁移前快照可从游戏菜单导出。15.0 新局仍可使用规则 AI，也可在模型设置填写自用的 Base URL、模型 ID 与 API Key。当前模型服务协议为 35。

## 王朝兴替

在地图打开「王朝政务」，选择执政方向和制度，设定征发、通运、赈济和留存额度，核对下一季国库、民仓与地图变化后颁布。朝廷、州郡和战区都能设置主官与副手。地方与中央分收产粮，遇封关、围城和拥堵时，粮队会改道或待通。

多方集团支持通行、实际交纳盟粮和派军守备。中止互市会阻碍贸易。接管原有争议城后，可和签约对方实施地方共治。全国待决按季收录欠缴、地方危机和换帅等事项。

达成统一、共守或承平后可继续守成。安排继位、裁撤战时征发，必要时付费续定交班停战，连续维护地方供给并完成交班后结卷。9.0 旧档可从「菜单 → 王朝兴替」升级，保留原战区和钱粮账目。

内置 ImageGen 生成了 [campaign-terrain.webp](dist/assets/campaign-terrain.webp)。提示词要求 3:2 的四格汉末写实图集，统一高位观察视角与自然光，分别绘制长江舰队、雾中山路、城外围营和傍晚驻防。各格留出可布置军阵的前景，画面无文字、现代物体或界面标注。

## 诸侯争衡

地图上的「全国方略」用于制定三年目标、分配每季钱粮和兵员，以及给主攻、牵制、护运与守备战区授权。战区共享预算和运输能力。优先级影响拨款、调兵及粮队到达时间，关隘和渡口单独限制同季通行。点地图上的战区标记可改配优先级、换帅、查看会战或转到军议处置。

预备军改隶会离开原编组，沿路线抵达后再编入新战区。敌方也会调兵增援、实施侧翼牵制或签订共同守备和约。连续推进会因新增紧急奏报暂停。地方页可处置征发争议，战略纪事记录实际的钱粮、战损与调度结果。

8.0 存档可从「菜单 → 诸侯争衡 → 升级当前存档」启用。八个剧本均保留 42 城。

战场季节素材位于 [battlefield-seasons.webp](dist/assets/battlefield-seasons.webp)，由内置 ImageGen 生成。提示词要求一张 3:2 四格汉末写实地景图，使用统一高位观察角度，分别画春雾江渡、积雪山关、雨中城墙和夕照秋营。各场景保留空旷前景供军阵合成，使用自然光和低饱和土色，画面无文字及现代物体。

## 天下秩序

从「菜单 → 天下秩序」可管理多年工程、地方委任和分期和约。

- **全国拨款**　从地图进入「天下经略」，在发展、守备、救济中选择优先方向。可同时推演现行方案和新方案的四季余额及工程进度。工程跨八季建设，设有修田、疏通漕运、边防和迁都。
- **州郡委任**　从全国总览批量委任，或单独给州牧设补任、征募、修复和调粮权限。地方延缴会减少入库，拒募时须处理民怨。可授事权、赈济或收回委任。朝局记录正统、支持度和继承摄政安排。
- **粮运和战后治理**　点粮运图上的城池查询地方库存、产出、通路和粮队。粮队逐季移动，受灾或封路会改道或停运。新接管城市可选择朝廷接管、留任地方官或分期整顿。
- **和约与纪事**　可附加停战期限、通行、共同守备、属城交割及逐季赔款。出现拖欠可以重谈。纪事按季回看疆域、粮队和前线。统一、联盟与承平结局还需连续三季维持财政和地方稳定。

## 国势与战局

全国军议可从「天下经略」或「菜单 → 国势与战局」打开。

- **全国军议**　给前线、守备和恢复划分全国额度，设置国库与储粮底线。用目标、统帅和战费批准战役，也可进一步约定撤退兵力、粮仓权限、增援及议和条件。
- **长期战役**　委任统帅会用实际钱粮集结与补给，可自行改用可通达的粮仓并调动预备队。战局跨季进入进军、交战和巩固。触及钱粮底线、失去粮道或收到盟军改约时，可在军议处置。目标达成或授权期满后，可以驻防、撤军休养或提出和议。
- **地图与战场**　地图标出战役进度和行军方向。点军团查看状态，从战场切换主攻、预备、护运和撤回。会战的据点、河流、城市和野战营地使用原创地景，记录可逐步回放，也可自动播放。
- **地方与人才**　长期转运会占用后方劳力，朝廷能安排恢复额度与人才委任。统兵、护运、守备和接管按实际行动累积履历。盟友可延长承诺期限或撤回军团，改约可以答复。

战场地景由内置图像生成工具制作。提示词要求一张四格原创汉末战场图集，以同一略俯视角和暖赭、墨绿画风绘制两岸渡口、山关、城墙与野战营地，留出投放军团的地面，只绘环境。资产位于 [battlefield-atlas.webp](dist/assets/battlefield-atlas.webp)。

## 山河会战

会战指挥可从地图「全国军议」打开。5.0 存档也可迁入全国军议，现有军团、战争、停战和行军路线随存档保留。

- **在地图上调兵**　标准剧本开局即有驻营军团。拉远看军旗，拉近可分辨步军、骑军、水军和车队。地图军队随真实兵力、驻地与粮运改变。敌军只显示本方取得的情报，并标明侦见时间。
- **从全国授权会战**　从地图的城市、据点或「会战指挥」进入，为军团分派主攻、预备、护运和撤回。委任模式可集结新军、调预备队、在缺粮或疲劳过高时撤回。手动模式可在季度之间调整部署，再交回委任。多条战线按同一国粮底线调拨。
- **同季会战**　敌对部队根据各自调令在道路、渡口或城外接触，随军粮、军械、兵种、疲劳和地形会影响战果。支援先完成行军，再结算攻城。受威胁的运输队会停发，有足够护卫才能继续。战报可按接报、接战和战果回看。
- **经营军团与盟友**　点军团可查疲劳、战损与履历，在己方安全城市安排整补、转编、换将、合编或归建。可以向盟友提出带期限和归属条款的会战请求。盟友自行选择具体军团或拒绝。

## 天下沙盘

地图上的「天下沙盘」进入战争、动员、政局和纪事。旧版战局可从「菜单 → 天下沙盘」启用。

- **战略据点**　八个剧本共用 42 城。另有 17 处可守备和争夺的关隘、渡口、港埠、军营和转运仓。在「据点粮道」点选目标，可查看控制方、驻防和通行状态。据点易主会实际影响补给、调兵和后方转运。
- **有限战争**　设定走廊、州郡或解围目标，授权将领集结。可在目标达成或形势不利时提议停战、通行或交还争夺城池，议和结算会处理赔款、撤军和交割。盟友可参加解围并派出援军。
- **生产和动员**　全国设钱粮底线，各州选择供粮、制械、转运或休养。生产会计入库存，由地方按可用路网转运。征兵占用劳力并影响后续粮税。军械可随补给补入在外军团。
- **政局与续局**　严重缺粮且离心的军团会预警。可补饷、招抚或撤换，放任持续可发展为兵变。可以接手脱离本方而建立的现存势力，保留同一世界的城池、军团与历史，继续推进。
- **连续推进与纪事**　可以一次推进最多四季，遇到重要战报、和议、会盟或军政危机时停在触发季度。纪事可跳到相应季度的疆域。AI 会独立发起战争、提议停战和召集会盟。模型配置由玩家在游戏内填写。

## 战线与天下

新开局启用 4.0。已有战局可从「菜单 → 总揽天下」启用。地图左上可进入国政与战线。

- **全国方针**　选择安民发展、全国备战或战后恢复。可用默认预算，或细调发展、军备、救济和钱粮预留。启用补任后，中枢优先为首府、整顿区和前线安排太守。各城事项可以交由地方官执行，已手动接管的城市继续沿用单独设置。
- **州郡授权**　选主管并授权经营、守备或赈抚。驻军底线决定何时优先征募，州郡预算按辖城分配。地方压力和武将离心会在国政入口提示。开仓、巡抚与增援会消耗实际钱粮并改变地方局势。
- **人才与归属**　人才方针可按季访才与补缺，也可集中招募在野人物、派使者登庸邻境待任人物。离心武将可能改仕。长期危机可导致乡民起义，低忠诚地方官也可能带城自立。新势力进入同一张地图并参加后续 AI 决策。
- **授权战区**　最多管理三条战线。选择攻坚、解围、争渡、野战或固守后可直接点地图设置目标。军团由将领按额度集结，寻找有路相通的粮仓，触及撤退底线时退回。地图上的战线标记可跳到授权和报告，手动对军团下令会收回该部的自动指挥。
- **议盟与开局**　可为各方约定主攻、屏护或筹粮，逐季记录履约。退出会结束后续义务并影响信用。自定义剧本可保存开局战区、已集结军团、粮仓和停战方。

## 山河变局

新局自动启用 3.0。旧局从「菜单 → 山河变局」在当前存档启用，保留季度、军团、围城、议约与人员。手动存档与 JSON 备份可保存新系统。

- **地图指挥**　点城进行建设、征兵、委任、任命和出征。点军团固守、改令、换粮仓或撤回。切到「关隘粮道」，点关隘封控或整修，点粮路安排运输，或取消已挂起的运输。
- **时令水陆**　夏汛影响通行，冬雪增加山道运耗。关隘加固会改善后续季度的通行。军团可选水路或陆路，受阻时尝试改道。点地图上的时令可查看战役复盘和接战数据。
- **州郡与仓储**　城池面板可为本州选择军械工坊、赈济修复或商埠互市。军粮与军械可以转运，军团组建时按驻地库存领用军械。仓库容量、道路、运费和国库储粮底线会限制运输。
- **多方议盟**　可以邀请两方，共定目标、停战通行、商埠互市、粮援和战后归城。各方独立表决。战事与粮援按实际履约记账，议约到期按条款交割。
- **剧本**　新增 184 年「黄巾起事」和 234 年「五丈原」。自定义方案可设置城池、兵粮、人物、难度、目标和初始信用，并以名称保存在本浏览器中反复开局。

在「模型设置」填写 Base URL、模型 ID 和 API Key。3.0 服务为各势力提供本方观测情报、信用履历、政令和议盟候选。模型故障时由规则 AI 结算当季。

## 天下大势

- **地图与军路**　远景看势力，中景查看州郡、关隘、渡口和粮路，近景查看城池和军团。控制关隘的势力可以调整军路通行。通过议约借道的军团会随路权变化改道，接管城池时实际继承城中的存粮。
- **调度**　先设全国每季上限与储粮底线，再按州郡分配额度、指定粮仓，并选择发展、守备或接管。地方调度会扩建屯田、补充前线驻军或赈济民众。运往粮仓的粮从国库实扣，并承担道路运耗。
- **联合战役**　给同一个目标编入主攻、策应和护粮军团，核对集结军粮、预计到位季度，再决定启用。主粮仓失效会尝试备用粮仓，可在战役现场改道、调整撤军预案、调用驻地预备队或撤回。开启战后接管的战役在钱粮许可时每季最多拨 6 钱、8 粮。
- **议约**　可把停战、返城、赔款、军路通行、粮援和合兵放进同一份议案。获批后次季逐项复核并交割。已履约的条款及未完成的原因会分别记入履约记录，并影响双方信用。停战与军路授权各有效六季，通行还须有有效的和平关系。
- **长局**　对手按各自局势制定四季方针，关注扩张、边防、民生或通商。新加入 190 年「关东联军」与 219 年「荆襄争夺」。从开局界面可调整城池归属、各方钱粮和人物驻地，再以自定义名称开局。

四季方针与双边打包议约可在「菜单 → 天下大势」管理。

## 天下演变与王朝传承

新局自动启用天下演变。已有存档可从「游戏菜单 → 天下演变」选择启用，接着使用原有季度、城池、官员、军团、协定和政令。三个手动存档槽与 JSON 备份均支持天下演变。

- **州郡**　按辖区查看驻防、民心、整顿中的城池和地方压力。可同时委任四个州郡，按季拨款赈济、安集守备或恢复商路。高压会先预警再演变为危机。长期失控时部分城池可能脱离，成立能自行决策的新势力。
- **继任**　现任在任期内可以指定继任者和代理人，也可安排下一季交接。群臣支持受继任者政务、国势军心和地方压力影响。继任受阻时由代理人执政四季，再进行交接。人物履历保留转仕和接任记录。
- **议和**　议案经双方批准后，下一季检查钱粮和领土归属，再按约交割。可支付赔款、返还对方曾拥有的主城。保护协定持续十二季，受保护方继续独立执政。连续维持六季稳定保护关系后，双方可协商合并，交接辖城、人员、军团和国库。无法交割会留下违约记录。
- **纪事与结局**　按季度回看疆域及同期事件，保留最近 180 帧疆域和 260 条事件。八个剧本各有一项国政议案。可占领 42 城统一、完成同盟条件取得「诸侯共守」，或在成功继任、履行和平协议和持续安定后确认「天下承平」。

在「模型设置」填写自己的 Base URL、模型 ID 和 API Key。新版服务会为每个仍有主城的对手分别征询军政决策，包括分裂后成立的势力。模型超时或返回无效时，该势力当季交由规则 AI。新版页面连接旧版服务时，已启用天下演变的存档使用本地规则推进。

## 战役指挥

新局自动启用战役指挥。已有战局可在「菜单 → 战役指挥」启用，继续使用原有季度、军团、官员和战区。

- **战役**　先设战区辖城、粮仓、目标和主将，再选主攻、牵制或解围。可设置兵力上限、撤退线和撤往地点，检查到位季度、渡口险道、敌援方向和拨粮上限。从战役页可调整本线军费、定位路线或接管军团。
- **围城与撤军**　强攻按到位时的实际战况结算。围困需要连续补给，敌援可以解围，孤立守军可能投降。牵制可封锁目标城的粮道和商路。达到撤退条件时，军团优先按预案撤回。退路易主或被封锁时，奏报会提示改道。
- **军情与盟军**　城池归属公开。敌军驻兵和城防按边报、侦察和盟友通报显示，旧报会放宽估计，无法确认时显示未知。每季可花 6 粮派一支斥候，最多两支。合兵提案可指定到位窗口和合击、牵制或解围策应。双方实际出兵后记入履约，逾期、同盟终止或目标易主会留下回执。
- **接管与复盘**　可以一次委任多座待整顿城，并自动纳入后续攻占的城池。接管按剩余政令位和预算拨驻军、任太守及赈济，整顿完成后恢复税粮和通行。剧本页有按时代设计的战役任务，复盘保留关键阶段、粮道、盟军贡献与接管记录。

模型服务提供战役候选，所有势力按各自掌握的情报拟令并接受同一套规则校验。

## 天下格局

新开局自动启用 1.1 规则。已有战局可在「菜单 → 天下格局」启用，接着使用原有季度、政令、城池、官员、军团和协定。人口和民心以升级当季的城池整顿状况初始化。旧档和三个存档槽仍可读写。

- **预算**　分配发展、军备和救济的每季上限，可设置钱粮预留和拨款优先级。手动政令先结算。战区按军备及各战区限额调拨，后续城池委任共享剩余军备预算。预算试算可在账目里逐城核对。征兵消耗人口，战乱与歉收影响民心，赈济和休养可促进恢复并影响后续税粮。
- **外交**　可从同一面板商议停战、同盟、通商、粮援与合兵。通商协议有效八季，商路畅通才入账。可经同时授权双方通商的第三方领地转运。撤回通商许可会降低信用，城池易主或断路会标出中断地点。粮援按约一次性交割，双方使用同一笔实际粮食。合兵要求两方在同盟有效期间向共同敌城出兵，履约或逾期记入信用与奏报。
- **官职**　可任命内政、外交和军务官，另指定代理人。满足能力要求的内政官节省发展与赈济费用，外交官影响接受提案的意愿，军务官减少长距离运粮损耗。任免、接班与功过可从官职页查看，最近一项也显示在人物资历页。
- **账目**　提供拨款预演、当季预估与季末实账，包括商路收益、援粮流入流出、救济开支和期末结余。可切换辖城查看当前人口民心及该账期的委任结果。
- **结局**　联盟路线要求本方和两位盟友保住核心城、有足够信用并保持通商，连续四季达标且战局已推进至少十六季时可确认「诸侯共守」。208 年「赤壁前夕」有独立人物、开局边界、事件和剧本路线，使用统一城池路网。剧本以历史背景设计为玩法开局，城池分配按战役规模作了取舍。

「新开局」随所选剧本和势力显示治所、辖城、临敌城、驻军、文武、钱粮、对手和阶段目标。「辖城」可分页查看治所、临敌情况、驻军和城防。「文武」可按统率或政务排序，查看每人在开局时的驻地。确认开局前可以切换剧本和势力进行比较。

「菜单 → 本局指引」可查看当前剧本、势力与季度，并打开分组委任、军议、政令队列和奏报。指引中也能打开新开局和模型设置。

## 战区指挥

「菜单 → 战区」可并行配置三个战区。为每个战区指定辖城、治所、粮仓、主将、任务、优先级、最低驻军与军费。可把已在外的军团编入战区，也可让进攻战区自行下达集结令。缩远到势力图可直接点治所附近的战区标记，拉近到城池图查看军团和补给。

战区使用玩家手动下令后剩余的政令位。全国军费按优先级覆盖各战区的自动动员、增援、征募和补给，保留已设置的钱粮预留。固守或接管任务可以调兵、补任太守并利用现有整顿规则。治所或粮仓失守、兵力不足或遇到有效协定时，对应战区暂停并发奏报，其他战区仍按各自条件结算。可从奏报或国政待办进入战区。单独接管军团会将其从原战区调出，重新编入后可继续委任。

可在「辖城与部属」指定备用粮仓。主仓失守或原粮道中断时，军团可沿本方道路切到备仓，恢复时也有奏报。运粮成本随路长变化，可以从军团改道面板预览。

## 国政与人物

「内政」可批量委任己方城池，补任空缺太守，统一设置发展方向和每城每季的预算。确认前可打开「本季预演」，查看拟补任人员、各城执行结果、所选城支出和全国季末钱粮预估。推进季度后可在「奏报」中查看结算和对手拟令。手动存档和自动进度都保存在当前浏览器。

「势力 → 国政总览」汇集辖城的驻军、税粮、委任和整顿状态。可以按前线、后方与治理方式筛选，按驻军或产出排序，查看单城或批量委任筛选结果。

「国政总览 → 前线驻军」对照当前与队列后驻军，按临敌城市的缺口排序，另列受停战或同盟保护的城池。目标默认 1,800 人，可在当次战局临时调整。拟调援军优先从后方选来源，使用前线援军时保留来源城的目标驻军。草案在原调兵面板确认后入队。

「前线驻军 → 多城援军」根据剩余政令位置逐城拟定援军。每拟一道，都重新计算后续可用兵粮。预案可查固定路线、来源留守、到达兵力、合计耗粮和仍有缺口的城市。确认后，整组按预览顺序追加到已有政令。

「前线情报 → 出征机会」集中列出按当前队列预估占优的相邻敌城。每个目标给出一份用兵较少的草案，显示出征城、领兵武将、战力、耗粮和来源留守。选中后可在出征表单调整并确认。

「菜单 → 军团」可组建常驻军团，每个势力最多同时拥有两支。集结令占一个本季政令位置。预览会给出目标、道路、预计交战季度、随军粮、城内留守和当前战力。组建扣除集结城兵力和两季随军粮，随后在下一季完成集结，再沿最多四段道路推进。原有相邻城出征仍可从单城使用。

军团通过己方道路从粮仓补充随军粮。粮仓或道路失守时，军团停步固守，继续消耗随军粮，断粮会造成减员。可改选粮仓和目标，或沿可通行路线退入己方城池。固守及战后驻扎的军团会参与所在城防御。占城后，人数充足时自动留 400 人整顿，剩余兵力可续进或驻入城中。税粮实账列入军团领粮和归粮。势力图显示战线，城池图还显示军团和虚线补给路线。

对手可用同一套规则组建军团、增援受威胁城池或袭击敌军粮仓。模型的军团候选政令由新版游戏服务提供，旧版接口仍能返回其他政令供浏览器结算。

「前线情报 → 守备压力」对照当前和队列后守备，按各城相邻敌方可投入的最高战力试算。城防、守将、有效协定和敌方现有兵粮都会影响结果。可能失守的城可查看援军能补足多少，并进入原调兵表单确认。对手实际政令在结算时产生。

「奏报 → 对手拟令」可同时查看拟令来源、理由与实际回执。回执显示执行、攻占、进攻失利、取消原因或休整。有关战报、人物档案和城池可直接打开，旧档仍可查阅原有拟令。

点选势力名单中的对手名称可查看势力简报，包括现有辖城、驻军、协定余期、当前战略与最近有记录的拟令。简报可定位对手现有的城市，或打开已按该势力筛选的奏报。

简报的「辖城清单」可按城名搜索或按驻军从多到少排序，显示当前辖城的城防、太守、守将和整顿进度。每座城都可以直接在地图上定位。

从辖城清单打开「出征机会」，可查看队列结算后预计仍属该势力、且能拟定占优出征令的目标。选中后可调整出征草案并确认入队。返回时保留辖城清单的筛选、排序和页码。

在全局或势力专属的「出征机会」打开「多城出征」，可选择拟令数量，逐道查看目标、武将、兵力、耗粮和来源留守。每拟定一道都按新的队列重新评估后续机会，整组确认后才会按预演顺序入队。

简报的「疆域履历」列出最近 12 季奏报中该势力可确认的攻占与失守，最新的变动在前。每条可定位当时交战的城池，带战斗结算明细的条目也可打开战报。从战报返回时会回到履历原页。

「国政总览 → 分组委任」可分别设置前线和后方的发展方向与每城预算，也可让一组沿用原设置。两组共用一次人员和财政预演，可逐城查阅拟补任太守、重点顺序和执行受阻原因。

「发展方案」提供三套可调整的预设。均衡发展让前后方自主建设，积蓄粮草让两组专注屯田，巩固边防让前线建设城防、后方屯田。预算按项目成本填写，手动调整后显示为自定义。看过预演并确认后，委任才生效。

「对比方案」按当前城池、队列和财政预留独立预演三套方案，可比较各项建设的执行数、太守人选数量、预计收支和暂缓原因。选用时会填入对应配置，随后可查看逐城预演并确认。

「国政总览 → 委任优先级」可选最多五座已委任的重点城。季末先为重点城尝试执行委任，其余按惯常顺序执行。编辑时可预览钱粮不足会影响哪些城，保存设置后才应用。批量委任预演和财政实账均标注重点城。

单城、批量或分组委任可以选择「自主发展」。太守每季从屯田、商贸和城防中选一项，优先建设等级较低的项目。同级时依次尝试屯田、商贸、城防，跳过满级和当季负担不起的项目。单城预算旁的「预演」可打开该城的预计执行结果，财政和奏报可查看季末实际项目。

「势力 → 人才」汇集本势力人物的驻地、政务、统率、职务和待执行的出征令。按状态筛选、按能力排序，或按姓名和驻地搜索。「战后迁出」可查看本势力人员最近一次有记录的战后去向，并打开原战报。待任人员可确认后调驻己方城池，或填补空缺的太守、守将。

「国政总览 → 职务空缺」按职位和前线、后方、整顿中筛查己方城池。预计补任可加快整顿的太守空缺与前线守将空缺优先显示。选择空缺可查看候选人，并按预填的职务和城池确认任命。

从人才名册或奏报可以打开人物档案。档案展示当前身份、驻地和任务，履历按时间列出领兵、守城、战后迁出和实际发生的任免调驻。人事记录列出原驻地、原职务和变更后的去向。可以筛选战事与人事，或从对手的人事奏报直达其档案。已经领到出征令的人物可从档案直达对应的队列位置。

己方现任人员可从档案的「调整职务」改任空缺岗位，或卸任并留在原城。确认前可查看原职、新职及原城的委任变化。跨城调任会同步改变驻地，整个变动记为一条履历。

「势力 → 财政」把城池税粮、同盟商贸、外交礼金、政令与委任支出分开列账。可切换本季预估和已结算季度的实账，也可查到每座受委任城池的执行结果以及国库、储粮或本城预算的缺口。

「财政 → 季度走势」可切换国库和储粮，查看最近 12 个保留季度的季末结余及相对本季开账的净变动。虚线框标出缺失实账的季度。点选季度可读取数值，并在有实账时打开明细。

走势中的「委任」用柱高表示委任城数，用亮色表示已执行城数。点选季度可查看实际建设与征兵、钱粮支出、未执行原因，并打开该季逐城明细。缺账和本季无委任分别标示。

「委任执行」可筛选已执行、未执行和各类原因。点选走势里的原因会打开对应季度并套用该筛选，可继续查看或定位匹配的城池。

本季委任预估中的「补足预算」按项目所需金额批量拟定新预算。预案会重新估算预计项目、其他城池受影响的结果和季末钱粮，再由玩家确认。新预算随战局保存，委任支出在季末结算。

在「财政 → 钱粮预留」可为全国委任设置国库和储粮预留额，填零可取消对应预留。本季预演会列出预计延后、改选或恢复的项目及季末余额，确认后生效。委任在税粮与政令结算后依照重点顺序使用预留额以外的钱粮。财政实账保存当季的预留额，奏报标记因预留暂缓或改选的项目。

「菜单 → 存档管理」有三个独立手动槽。各槽可存入、载入或导出 JSON，覆盖有记录的槽时可先核对并确认。菜单的快速存档与读档使用槽 1，原有手动存档也在槽 1。可导出当前战局，或从其他浏览器和电脑载入 JSON 备份。载入后更新当前自动进度。

地图上的「前线」和国政总览中的「前线情报」可查看相邻外城、驻军差距、约定保护和可调援军，直接定位或进入相应出征、调兵表单。队列内的调兵与占城会计入预估，最终以季度结算为准。

在「前线 → 联合拟令」可一起选定援军、进攻城、武将和目标。可用三段己方道路内的援军。预览列出固定路线、两道军令的顺序、总耗粮、两城原驻军和留守兵力、出征上限及预计战力。确认后将调兵与出征依次加入本季队列，占用两个队列位置。

顶部「军议」每季最多提供三条基于当前战局的建议。可直接打开来使、委任预算、任命、内政或已填好的出征草案。相邻援军不足时，也会检查可执行的跨城支援方案。正式下令和季度推进由玩家确认。

「奏报」默认打开上季摘要，可查看攻占、失城、政令取消、实账净变动与待答复来使。「结算」可跨全部已保存的季度查阅，并按涉及势力或交战、占领整顿、调兵、外交、内政等类型筛选。交战记录的「战报」展示领兵武将与守将、双方投入兵力、实际战力和伤亡。攻占后的「人员去向」可查本战迁出的人员、原职务，以及当时移驻的城池或无驻地结果。旧存档保留已有战报。带城池定位的记录可回到地图查看位置。

玩家每季可排入最多三道国家政令。在「调兵」中选相邻己方城池调动驻军，再到接收城的「出征」页安排进攻。出征预估计入排在前面的援军。「查看队列」可重排、撤销并查看下令后剩余的钱粮。依赖援军的出征须排在调兵之后，太守的委任任务仍在季末结算。

「查看队列 → 逐令预演」可按当前顺序查阅每道政令的支出、驻军变化、预计战果和前置要求。

「调兵」也可选两到三段己方道路可达的城池。预演按队列后的归属显示最短路线、原城留守及各段总耗粮。跨城调兵占一道政令，沿途城市仅供通行。结算时路线受阻，整道调兵令取消。「前线」的援军列表和「整顿中」的援军入口也能拟定远程调兵。

新占城由带队武将驻守。整顿期间税粮减半，驻军达到 250 人后每季推进整顿，有太守时可以加快。整顿结束后恢复委任任务，并从下一季起收取全额税粮。

「国政总览 → 整顿中」可对照当前和排队后驻军，查看太守与季末整顿进度，也可拟定援军或补任太守。预计攻占的城池也会列在这里。己方现存的占领记录可从「奏报」直达对应城池的整顿信息。

「整顿中 → 整顿援军」按现有队列优先为驻军不足的已占城拟调兵，再安排预计攻占的城。预案列出调兵路线、来源留守、合计耗粮、补兵后的缺口和整顿进度。攻占当季暂停整顿，驻军达标后下季具备推进条件。确认后按预演顺序整组入队。

「整顿中 → 批量补任」优先为本季能够推进整顿的城池补任太守，先安排城内待任人员，再按政务从其他待任人员中选任。预览逐城显示人选、原驻地、驻军缺口和预计季末进度。确认后，任命即时生效并记入人物履历。

「整顿中 → 接管预案」把援军和补任太守放在同一次预览里。预案先核算调兵后的驻军，再为能够推进整顿的城池优先选任太守。逐城可核对路线、武将和整顿进度。确认后太守即时到任，援军按预演顺序加入队列。

占领全部 42 座主城时获胜，失去全部城池时战败。终局会停止推进季度，可继续查看地图、奏报或存档。进行中的剧本可在「菜单 → 查看战局」查看控城进度。

四个剧本分别有可选阶段目标。199 年发展委任屯田，208 年建设商埠，262 年整备前线驻军与城防，265 年攻占城池并完成整顿。阶段目标在季末验收，完成后保留在存档和奏报中。

「国政总览 → 阶段目标」可分页查看逐城进度和条件缺口，并定位到地图。265 年剧本在暂无新占城时可直达出征机会。已验收的季度与当前达标城数会同时显示。

「菜单 → 战役方略」可查看每个剧本的三段战役路线，按季末达标顺序推进。中期考核储粮或国库与核心城，后期考核扩张和整顿。弱小开局的部分目标按初始辖城数调整。完成路线后仍可继续统一天下。

「国政总览 → 常设国策」可为前线和后方分别设发展方向、每城预算和最低驻军，也可预留全国钱粮。太守随季末实际边界调整，驻军不足时优先征兵。调整单城治理后，该城转为手动接管，可从「待办」交回国策。「待办」汇总太守空缺、驻军缺口、预算或预留阻塞。停用国策后，各城继续当前的委任安排。

战役事件在符合条件的季度出现。举荐可资助文官历练，军务继任可任命守将，边军归降可拨粮招纳部众。「战役方略 → 事件」可接受或婉拒，并查看处理结果。人物档案的「资历」记录成功委任、镇守前线和领兵所得的成长，提拔后的政务影响委任成本，统率影响出征和守城战力。

「菜单 → 招揽人才」可在第 4 和第 8 季以后招揽虚构候补人物。支付礼金并选定己方驻地后，即可在人才名册分配职务。各剧本在第 13 季以后还有独立事件，分别处理流民归耕、修缮粮道和安置新附州郡。

「菜单 → 查看战局 → 战役结局」列出各剧本的结束条件。推进至少 16 季，完成三段战役目标并达到核心城、稳定辖城和钱粮要求后，可主动确认对应的剧本结局。统一 42 城或失去全部城池会自动结束本局。终局可分页查看疆域、关键战役及人物表现。旧存档从首次使用新版规则结算后开始累计复盘资料。

在「势力 → 外交」可向其他势力提议两季停战或四季同盟。对方会根据边境、兵力和共同对手作出答复，接受后立即生效并支付礼金，拒绝时保留礼金。同盟在互不进攻之外为双方带来每季 4 钱商贸收入。与对方有待执行的出征令时，须先撤销该令。有效期、答复和期满记录可在外交与奏报中查看。

对手也会根据前线、共同对手及当前战略主动遣使，模型执政与本地规则模式共用这套外交规则。收到来使后可在「势力 → 外交 → 来使」接受或拒绝。接受时由提议方支付礼金，推进下一季前未答复则自动失效。

## 模型设置

推进季度时，「势力」可查看各对手的拟令状态和已处理数。单个模型请求失败时，该势力交由规则接管，季度仍一起结算。拟令连接中断时，本季由本地规则结算。

逐势力实时进度由新版游戏服务提供。已运行的旧版服务仍可照常完成整季结算。

在游戏右上角打开「菜单 → 模型设置」，填写 Base URL 和 API Key。接口使用兼容 Chat Completions 的格式，地址可以填写包含版本路径的 Base URL，也可以填写完整的 `/chat/completions` 地址。模型 ID 可手动输入，也可通过「读取模型」加载候选。模型列表只有一项时，留空保存即可采用这一项。

填写模型 ID 后，可点「测试连接」发送一次简短的 JSON 探测。测试沿用同地址已保存的 API Key，也可使用本次填写的 Key。测完可单独决定是否保存，战局不会随测试请求发送。此功能由新版游戏服务提供。

API Key 存在本地服务进程内存中。刷新页面后可继续使用，重启服务后重新填写。保存后游戏切换到模型执政。各势力独立拟令，天下奏报展示理由和结算结果。模型待配置或请求失败时，可以由规则接管。

各对手分别选择积蓄粮草、稳住前线或争夺邻城。进入中期后，目标可延续四至五季，并在钱粮吃紧或边城面临失守时调整。共同强敌可促成同盟，两线受压可促成停战，其他势力之间签订的协定也会记录在奏报。边城缺少可出征武将时，对手可从后方调派守将，也可为新占城补任太守。可在「奏报 → 对手拟令」查看各势力的目标、调整原因和结算结果。仍在运行的旧版服务可提供单季拟令，浏览器按当前版本规则校验和结算。

进入长局后，各势力可从可用辖城争取增援或招揽未入仕的人才。同盟临期时会根据城池和兵力重新评估续盟，现有协定持续至约定到期。新版游戏服务会将战区增援纳入模型候选政令。

模型决策包含本势力预算底线、协议、近季履约记录，以及独立的军事、外交和国政候选。服务复用同一个结算中的回合结果，并短时保留最近一份完成结果以处理重试。

对手可把有太守的直辖城委任为屯田、商贸或城防。完成一个方向后，也可改派到其他尚可发展的项目。新增或改派各占一道政令。太守按季度执行，并给征兵保留钱粮。委任预算和当季成果可在「奏报」查看。

## 项目结构

- [回合规则](dist/engine.js) 处理任命、政令、季度结算、攻占和存档校验。
- [军团与补给](dist/armies.js) 管理集结、行军、守备、撤退和粮仓连接。
- [战区指挥](dist/theaters.js) 管理委任、优先级、预算以及结算。
- [国政与人口](dist/realm.js) 管理全国预算、城市民生和国级官职。
- [天下演变](dist/polity.js) 管理升档、州郡危机、政权交接、疆域纪事与承平结局。
- [通商与联盟](dist/accords.js) 管理共享道路、外交条款、履约信用与联盟条件。
- [战役结算](dist/war-operations.js) 管理围城、解围、封锁和战役阶段。
- [前线情报](dist/war-intel.js) 管理各势力战场可见信息和侦察结算。
- [游戏界面](dist/index.html) 和 [界面控制](dist/app.js) 展示国情、城池和奏报。
- [地图渲染](dist/map.js) 根据当前城池归属着色。
- [模型决策](ai.mjs) 按势力准备候选政令，并将通过校验的政令交回引擎。
- [势力战略](dist/strategy.js) 生成可执行的目标与行动，并评估跨季度进度。
- [外交规则](dist/diplomacy.js) 管理停战、同盟、商贸收入与提议判断。
- [阶段目标](dist/objectives.js) 按剧本计算阶段目标的进度。
- [战役路线与人物成长](dist/campaign.js) 管理跨季里程碑、事件和提拔。
- [财政账目](dist/finance.js) 汇总收支并校验历史账目。
- [存档备份](dist/saves.js) 管理可迁移的游戏存档格式和校验。
- [模型服务](model-service.mjs) 管理游戏内填写的连接配置，并调用上游模型。
- [世界数据](dist/assets/world.json) 包含统一城池名录、剧本开局、近似疆界、人员和游戏路线。
- [剧本人物](dist/personnel.js) 扩充各势力可任用的武将和官员。

## 验证

```powershell
npm test
```

规则测试包含八个剧本的 16 种势力开局，推演至 100 季或自然终局，逐季备份和读取。完整终局用例从标准开局验证统一、联盟与承平。浏览器验收覆盖桌面、手机触控、窄屏、模型故障回退与读档。

完整游玩验收使用 Python 和 Playwright。首次安装依赖后，在项目目录执行脚本。脚本优先使用 Windows 已安装的 Edge，也可使用 Playwright 的 Chromium。

```powershell
python -m pip install playwright
python -m playwright install chromium
python test/browser/campaign-smoke.py
python test/browser/frontline-smoke.py
python test/browser/high-command-smoke.py
python test/browser/century-smoke.py
```

脚本启动独立的本地游戏服务和模拟模型服务。验收桌面、窄竖屏与短横屏的开局、地图缩放、战役预演、围城、接管和旧存档恢复。模型验收覆盖独立拟令、失败接管和重复请求。规则回归含四个剧本的八组 40 季长局、剧本战役路线、两线断粮与援军、围城被解后重组，以及从普通开局推进至联盟结局和全城统一。

人员能力、出征战力和季度产出为首版平衡数据。199 年士燮的广西交州一带疆域在地图中作为地理参考。
